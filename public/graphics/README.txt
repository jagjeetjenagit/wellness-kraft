Put your generated homepage images in THIS folder.

Save each file with the EXACT name shown below (all lowercase, .jpg):

  hero.jpg            — big image next to the headline at the top
  approach.jpg        — image next to "Why we're different"
  lifestyle-band.jpg  — wide banner near the bottom of the homepage

Until a file is added, the website shows a tidy labelled placeholder in its
place, so nothing ever looks broken.

The ready-to-paste image prompts (and the size to generate each at) are in
IMAGE-PROMPTS.md in the main project folder.
